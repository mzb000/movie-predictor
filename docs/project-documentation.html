1. Project Overview

Movie Predictor ek full-stack machine learning application hai jo movies ki rating predict karta hai, hit/flop classify karta hai, aur similar movies recommend karta hai. Yeh project synthetic movie data generate karta hai, ML models train karta hai, aur results ek beautiful React UI ke through dikhata hai.

Key Features

🎲 Random PredictionHar click pe nayi random movie ki prediction
⭐ Rating Prediction1-10 scale pe rating predict karna
📊 Hit/Flop ClassificationMovie ko Hit, Average ya Flop classify karna
🎯 RecommendationsSimilar movies suggest karna (cosine similarity)
🔍 Movie SearchTitle se movies search karna
🧪 Custom PredictionManual features daal ke predict karna

Data Flow

1
User clicks "Predict Random Movie" — Frontend predictRandomMovie() call karta hai
2
Vite proxy forwards — /api/predict/random → localhost:8000
3
FastAPI handler — Random movie pick karta hai dataset se (5000 movies)
4
ML Service — Features extract → MinMaxScaler → RandomForest predict
5
Response — Movie data + predicted rating + hit/flop classification + confidence

4. ML Pipeline

4.1 Data Generation (generate_dataset.py)

5000 synthetic movies generate karta hai realistic distributions ke saath. Har genre ka apna budget range, revenue-to-budget ratio, aur rating influence hota hai.

AspectDetails
Total Movies5,000 synthetic movies
Genres18 genres (Action, Drama, Comedy, etc.)
Directors15 directors (Nolan, Spielberg, Tarantino, etc.)
Languages10 languages (English dominant)
Budget Ranges$1M-$350M (varies by genre)
Rating InfluenceGenre-based adjustments (Drama +0.8, Horror -0.5)

4.2 Feature Engineering (preprocess.py)

Raw CSV data ko 31 numeric features mein convert karta hai jo ML models use karein.

31 ML Features

CategoryFeaturesCount
Numericbudget_log, popularity_log, vote_count_log, runtime, is_english, revenue_to_budget, cast_size, release_year, release_month9
Genre Flagsgenre_Action, genre_Adventure, genre_Animation, genre_Comedy, genre_Crime, genre_Documentary, genre_Drama, genre_Family, genre_Fantasy, genre_History, genre_Horror, genre_Music, genre_Mystery, genre_Romance, genre_Science_Fiction, genre_Thriller, genre_War, genre_Western18
Season Flagsseason_Spring, season_Summer, season_Fall, season_Winter4

Key Transformations

budget_lognp.log1p(budget) — log scale
popularity_lognp.log1p(popularity)
vote_count_lognp.log1p(vote_count)
revenue_to_budgetrevenue / budget ratio
is_english1 if English, else 0
hit target2=Hit (rev>3x), 1=Avg, 0=Flop

4.3 Model Training (train.py)

Rating Prediction Model
RandomForestRegressor 200 trees max_depth=20 
Algorithm: RandomForestRegressor
Trees: 200  |  Max Depth: 20  |  random_state: 42
Target: vote_average (1-10)
Scaling: MinMaxScaler
Split: 80/20 train/test
Metrics: RMSE ≈ 0.52, R² ≈ 0.38
Hit/Flop Classification Model
RandomForestClassifier 200 trees max_depth=15 
Algorithm: RandomForestClassifier
Trees: 200  |  Max Depth: 15  |  class_weight: balanced
Classes: 0=Flop, 1=Average, 2=Hit
Split: Stratified 80/20
Metrics: Accuracy ≈ 92%
Recommendation Engine
TF-IDF + Cosine Similarity 
Text Features: genres + keywords + overview (combined)
Vectorizer: TfidfVectorizer (max_features=3000)
Similarity: cosine_similarity matrix (5000 x 5000)
Output: Top-N similar movies with similarity scores

Hit/Flop Target Definition

LabelIDConditionColor
Hit2revenue > 3× budget#4caf50
Average1revenue > budget#ff9800
Flop0revenue ≤ budget#f44336

5. Backend (FastAPI)

5.1 Entry Point (main.py)

FastAPI app create karta hai, CORS middleware add karta hai (all origins allowed), aur 3 routers register karta hai.

# Key configuration
app = FastAPI(title="Movies Prediction App", version="2.0.0")

# CORS — allows all origins for development
app.add_middleware(CORSMiddleware, allow_origins=["*"], ...)

# 3 API Routers
app.include_router(movies.router)    # /api/movies/*
app.include_router(predict.router)   # /api/predict/*
app.include_router(recommend.router) # /api/recommend/*

# Run: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

8. React Components

Pages

Home.jsx
frontend/src/pages/Home.jsx

Landing page with "Predict Random Movie" button. Har click pe GET /api/predict/random call hota hai aur nayi movie ki prediction dikhti hai with fade-in animation.

State: result (movie + prediction data), loading (boolean)

Shows: Movie title, tagline, genres, director, runtime, year, overview + AI prediction card (rating, actual vs predicted, hit/flop badge with confidence %)

MovieDetail.jsx
frontend/src/pages/MovieDetail.jsx

Movie detail page — jab kisi movie par click karo to yahan aata hai. useEffect mein getMovieById aur predictMovieRating parallel call hote hain.

Features: Full movie info, AI prediction panel, "Get Similar Recommendations" button

State: movie, predictions, recommendations, loading, recLoading

PredictPage.jsx
frontend/src/pages/PredictPage.jsx

Manual prediction dashboard — 2-column grid with RatingPredictor (left) aur HitFlopPredictor (right). User khud features enter karke predict karta hai.

Reusable Components

MovieCard.jsx
frontend/src/components/MovieCard.jsx

Props: movie, onPredict

Clickable card with hover animation. Shows title, hit/flop badge (rating-based), genre tags (max 3), rating, popularity, director. Click → navigates to /movie/{id}.

Badge Logic: rating ≥ 7 = Hit (green), ≥ 5 = Average (orange), else Flop (red)

MovieList.jsx
frontend/src/components/MovieList.jsx

Props: movies, title, loading, emptyMessage

Responsive grid of MovieCards. grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))

SearchBar.jsx
frontend/src/components/SearchBar.jsx

Props: onSelect

Debounced search (300ms delay) with dropdown autocomplete. searchMovies API call on each keystroke (after debounce). Click result → navigate to movie detail. Click outside → close dropdown.

RecommendationPanel.jsx
frontend/src/components/RecommendationPanel.jsx

Props: recommendations, sourceMovie, loading

"Because you liked [movie]" header with list of recommendations. Each shows title, genres (max 3), rating, similarity score %. Clickable → movie detail.

RatingPredictor.jsx
frontend/src/components/RatingPredictor.jsx

Form with 9 numeric inputs + 18 genre toggle chips. Season auto-calculated from release_month. Calls POST /predict/rating. Shows predicted rating as large number.

HitFlopPredictor.jsx
frontend/src/components/HitFlopPredictor.jsx

Same form as RatingPredictor but calls POST /predict/hitflop. Shows prediction label with emoji (🔥 Hit, 📊 Average, 💀 Flop), confidence %, aur per-class probability bars.

10. Docker & Deployment

# docker-compose.yml
version: "3.8"
services:
  backend:
    build: ./backend
    ports: ["8000:8000"]
    volumes:
      - ./backend/data:/app/data
      - ./backend/app/ml/models:/app/app/ml/models
    environment:
      - MODELS_DIR=/app/app/ml/models
      - DATA_DIR=/app/data
    restart: unless-stopped

  frontend:
    build: ./frontend
    ports: ["3000:80"]
    depends_on: [backend]
    restart: unless-stopped

# Run: docker-compose up --build

11. Setup & Running

Option 1: Quick Start (Windows)

Generate Data + Train Models
